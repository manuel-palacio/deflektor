# Level files

Every `*.json` file here is loaded automatically, in natural name order. Adding a level needs no code changes:

- `original/NN.json`: the original C64 levels (generated by `scripts/extract_levels.py` from `levels.png`).
- `training/N-name.json`: the tutorial lessons (each has a `lesson` line shown when it starts).

Check every level with `npm run check-levels`, which runs structural validation and the solver. The game
also validates at start-up and refuses to boot with a list of problems and their positions.

## Format

```json
{
  "id": "my-level",
  "name": "My level",
  "emitter": "right",
  "energySeconds": 150,
  "tiles": ["15 characters", "… 9 rows"],
  "walls": ["30 characters", "… 18 rows (optional)"],
  "pieces": [{ "x": 7, "y": 4, "type": "splitter", "rotation": 4 }],
  "timeLimitSeconds": 60
}
```

**Tiles** (15 × 9): `.` empty · `E` laser (fires toward `emitter`) · `R` receiver · `0`–`f` mirror at that
rotation · `@` self-rotating mirror · `o` cell · `x` mine · `*` prism · `p` / `q` absorbing / reflecting
polariser · `T` `U` fibre-optic pair · `#` `=` `+` a whole tile of purple bricks / blue bricks / gate.

**Walls** (30 × 18 quarter tiles, optional): `#` purple brick (reflects) · `=` blue brick (absorbs) ·
`+` gate (reflects until the last cell is gone, then vanishes) · `.` none.

**Pieces** (optional; each replaces the tile at `x`, `y`, counted from 0):

| type | options |
|---|---|
| `mirror` | `rotation`, `turns` (limited turns), `fragile` (shatters after 1.5 s of beam) |
| `pod` | `moves`: `"horizontal"` or `"vertical"` (a moving target) |
| `splitter` | `rotation`: half-silvered, the beam passes and reflects |
| `oneWay` | `rotation`: reflects on its bright face only; the player can turn it |

**timeLimitSeconds** (optional) makes a timed level.

## Editor

Run `npm run dev` and open `http://localhost:5190/?editor`. Paint pieces and bricks, **Check** validates and
solves the level (showing par), **Play** test-plays it, and **Export JSON** gives the file to save here.
